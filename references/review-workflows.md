# 审阅与改稿检查方法

本文件把[18 条论文写作原则](writing-principles.md)落实到具体稿件，按本轮任务选用。以用户最新稿件、修订和授权范围为准；下面的方法不改变原原则的主次，也不要求每次完整执行。

按需读取：第 1 节用于结构关系，第 2 节用于主张与证据，第 3 节用于实际改稿的含义核对，第 4 节用于审阅意见和返修安排。可以结合使用，记录形式不限。默认只展示关键结果及必要依据；整稿审阅或明确要求时，再提供所执行检查的完整记录，包括已检查的关系、判断依据、覆盖范围与未决事项。材料不足时说明可判断的部分，不以记录齐全代替论证成立。

## 1. 反向提纲

**何时使用：**结构审阅、章节重组，或用户指出主线混乱、段落衔接不清。必须有现稿；没有现稿时，可以按任务拟定写作提纲，但不能声称完成了反向提纲。

**检查过程：**

1. 根据任务选定节级或段级范围，从实际内容提取各单元的主要判断、支撑材料、依赖的前提，以及它为后文建立的基础。保留可定位的位置；标题只能帮助定位，不能代替内容判断。
2. 沿现有顺序检查：必要前提是否在需要时可获得；证据到结论是否缺少推理；重复内容是否承担新的作用；材料是否偏离当前主线。稿件没有给出的关系标为缺口，不替作者补成已经存在的论证。
3. 区分现稿的组织与建议的组织。对需要调整的位置说明保留、移动、合并或补写的理由，指出该动作修复哪一条论证关系。若缺的是证据，单纯移动文字不能解决，应结合第 2、4 节判断。

**完成标准与边界：**判断能够回到稿件位置与实际内容，说明哪里缺环、重复、错位或偏题，以及为何需要或无需调整。局部结构任务采用足够的分析粒度，不扩展为逐句登记或全文重构。检查发现的问题可以尚未解决；给出调整方向不等于已经修改稿件。

## 2. 关键主张—证据对应

**何时使用：**完整整稿审阅、引言关键困难与本文回应的核查、贡献梳理、摘要与结论审阅、重要结果比较，以及因果或机制解释。聚焦决定主要贡献的主张及本轮涉及的内容，不为每句背景陈述建立记录。

**检查过程：**

1. 定位主张及其准确含义，明确研究对象、判断范围、比较对象与条件。找到对应的实验结果、理论推导或文献原文及其位置；条件包括影响判断的指标、单位、汇总层级、实验设置或推导假设。
   完整整稿审阅时，从引言提出的关键困难和本文声称解决的问题开始，逐项追踪到方法回应与验证结果。背景动机可由已有文献支撑；本文声称克服的困难则须有与该困难对应的证据，不能用总体性能或实验章节完整代替专项支持，也不要求每个背景句新增实验。
2. 分开记录来源状态与支持程度。材料是否提供、是否实际查阅、实验是否完成，是来源与工作状态；从中能推出什么结论，需另行判断。作者确认、文献确实存在、实验已经完成，均不能自动证明主张成立。
3. 阅读可获得的相关材料，核对其与主张之间的推理关系。重要比较检查条件是否可比；理论结论检查假设与适用对象；引用检查原文实际论述及版本；机制解释检查证据能否区分所提出的机制与其他可能解释。总体效果、组件贡献与机制成立应分别判断。
4. 按实际支持程度给出结论与理由：证据足以支持；仅支持部分范围或较弱判断；与主张冲突；或材料不足、暂时无法判断。指出支持到哪里、差在哪里，避免把证据缺失与反证混为一谈。

**完成标准与边界：**关键判断能够对应主张位置、证据位置、比较条件、支持程度及缺口；缺少某项信息时明确标出。计划中或运行中的实验不计为已获得的证据；未提供或未读到的材料不直接判为不存在。充分成立的贡献应直接表达，不能为显得谨慎而无依据地削弱；支持不足时，按缺口决定补分析、补证据或收缩主张。

## 3. 改稿前后的语义漂移检查

**何时使用：**实际重写、压缩或润色涉及方法、结果、贡献与结论的内容。审阅已有的一对版本也可使用；仅有单一版本时不能宣称完成前后比较。

**检查过程：**

1. 修改前保留当前文本或可比较的版本，确认其包含用户最新修订。若审阅既有改稿时缺少旧版本，明确无法完成前后比较；仍可检查当前文本的内部一致性，但不要把推测的原意当作旧稿。
2. 对照改动及必要关联内容，检查数字与比较口径、效果方向、否定、因果关系、适用范围、确定性、术语含义和引用归属。判断修改是否改变了科学含义，不以措辞相似度或读起来更流畅作为通过标准。
3. 纠正无依据的强化、削弱或归属变化。发现科学表述本身需要调整时，区分意外漂移与有依据的修改；属于授权范围的调整说明依据，并同步受影响的必要关联位置。超出授权范围或依据不足的事项先指出，不擅自确定新的科学结论。

**完成标准与边界：**改动保留了原有科学含义，或其含义调整有明确依据且符合本轮授权；无法完成的比较与未决事项如实说明。局部润色只检查改动及必要关联内容，不默认开展整稿审查。没有旧版本时，检查能力受限，不能用“未发现变化”代替“无法比较”。

## 4. 审阅问题按处理方式分类

**何时使用：**论文审阅、修改建议整理和返修规划。先依据稿件确认问题是否成立，再分类；处理方式不代表严重程度，同一问题可以需要多种动作。

**处理方式：**

- **措辞修订：**已有含义与依据成立，需要消除歧义、冗余或术语不一致，使表达准确。
- **论证重组：**已有材料之间的推理、顺序、主次或章节职责需要重新组织。
- **补充分析：**利用已有材料重新比较、推导或分析，回答目前尚未回答的问题。
- **补充证据：**取得现有材料尚未提供的支持；具体需要什么由主张与缺口决定。
- **收缩主张：**把结论限定到现有证据能够支持的对象、范围或强度，保留其中已经成立的贡献。

**检查过程：**

1. 给出问题的具体位置、内容依据与论证影响。材料不足以确认问题时，标明待核实的内容及其影响，不把猜测写成已确认缺陷。
2. 选择最低限度且足以解决问题的动作，说明为何需要这种处理。补分析针对已有材料，补证据针对尚缺的支持；若有不同可行路径，说明各自能解决到什么程度。
3. 按对当前任务和主要论证的影响安排优先次序。实施修改后核对对应问题是否解决；部分完成时，区分已完成动作与尚未关闭的缺口。

**完成标准与边界：**意见有位置、有依据、有影响说明，也有可执行的最小动作。分类完成不等于问题解决，措辞修改不能关闭仍然存在的证据缺口。尚需分析或新增证据的事项保留为待办，不自动启动实验；若通过有依据的主张收缩解决了本轮问题，也不宣称原来更强的主张获得了验证。
