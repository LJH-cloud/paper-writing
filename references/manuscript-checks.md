# 术语、表达与整稿核查

本文件落实[18 条论文写作原则](writing-principles.md)，与[审阅与改稿检查方法](review-workflows.md)配合使用，不改写原原则。用户明确限定的局部或专项范围优先；完整整稿审阅、投稿前终检必须覆盖下面各项中适用的检查，不能只挑容易完成的部分。

按任务只读相关节；默认展示关键发现、依据与待办。完整审阅以对象清单对照实际材料，保留可追溯的覆盖范围、稿件位置、判断依据和未决事项，区分已检查、待修和缺材料的项目；记录形式由材料决定，不强制固定表格或长期台账。缺少原文、图像或最终产物时，完成可检查的部分并保留待办，不宣称该项通过。

## 1. 有文献依据的术语核查

**何时使用：**首次整稿写作、整稿术语审查，以及尚无适用于当前稿件的已核实术语表的整体审阅。已有术语表时核对其依据和适用范围；局部任务复用已核实内容，只补查新增、歧义或含义发生变化的必要项。

**检查过程：**

1. 从研究问题、方法含义和实际操作识别需要核查的术语，优先处理核心概念、方法名称、关键操作与易混概念。先还原所指对象与操作，不能仅按稿件已有名字搜索。
2. 必须参考 `nature-academic-search`，广泛检索同方向和近邻路线，比较不同表述及其适用对象；选择代表性原始论文，按需补充标准和综述。综述用于定位与比较，关键定义和方法用法尽量回到原始来源。
3. 实际阅读来源中的定义、方法或相关上下文，核对术语指代、操作、条件与本文是否相符。搜索摘要、标题相似或高频出现只能提供线索，不能单独确立规范用法。
4. 建立术语表或等效记录，保留本文含义、规范候选、真实来源及具体位置与使用语境、适用边界和判断依据。只记录实际读到的内容；无法取得原文或无法确认定义时，保留未决状态。
5. 先依据外部证据判断，再决定全文用词及必要解释。稿内出现次数最多的表述不能据此成为规范；新定义在首次出现时交代含义，缩写在首次使用时展开。统一时同步核对正文、图注、公式说明、伪代码与补充中的含义。

**判断类别：**

- **已有通行术语：**来源中的含义与本文相符，采用其通行表述并保持一致。
- **误用：**本文指代或操作不符合所用术语的定义，纠正术语或科学表述，不能只做字符串替换。
- **表达变体：**同一概念存在合理表述差异，结合领域惯例和本文语境选择，不把变体一律判为错误。
- **合理的作者新定义：**确需区分的新概念可以命名，但应先明确含义、引入理由及与既有概念的关系。
- **不必要的命名：**普通操作或已有概念被重新包装，优先使用准确直接的表述。
- **未决：**证据不足、用法分歧或本文含义尚不明确，列出待核实的问题，不先强行统一。

**完成标准与边界：**依据覆盖了关键概念的定义、代表性用法与容易混淆的边界，能够解释采用或保留某个表述的理由，即可停止扩展检索；不按固定篇数凑材料。没有搜到某个名称不等于作者编造，也不能证明该名称有必要。检索未覆盖的领域或拿不到的原文应明确说明，不能用稿内一致性替代外部核实。

## 2. 防御性表达与实质限制

**何时使用：**贡献表达、结果解释、讨论与结论审阅，以及实际润色或压缩。必须实际参考 `anti-defensive-writing`，但本 skill 的原原则与用户范围优先。

采用其中直接表达已成立贡献、删除无信息辩解的做法；不采用因结果不利而隐匿重要信息、更换比较口径以回避结果，或把“性能下降”等事实表述列为禁词的要求。

**检查过程：**

1. 判断限定语是否改变读者对对象、条件、证据强度或适用范围的理解。实质限制保留在定义、设置或相应分析中；仅重复作者担忧、没有新信息的辩解可以删除。
2. 对不利或冲突的结果，按其对核心判断的影响决定讨论与材料位置。会实质改变结论的信息必须清楚处理，不能通过删除、弱化或移入补充使其失去可见性。
3. 解释权衡、目标差异或适用场景时，核对是否有相应证据；不能为了维护贡献而补造理由，不能在转述中悄悄更改指标、比较条件或汇总层级。
4. 对证据已经充分支持的贡献直接陈述；对支持不足的判断，转入[主张—证据检查](review-workflows.md#2-关键主张证据对应)，按实际缺口处理，避免以语气强弱代替论证。
5. 实际改稿后检查原有条件、效果方向与科学含义是否保留。内部检索状态、审计过程和修改流水账不直接复制进论文正文；正文呈现读者判断结论所需的事实、依据与限制。

**完成标准与边界：**删除的是冗余辩解，保留的是影响理解的条件和证据；贡献与限制均按实际支持程度表达。审阅意见只指出需要的动作，不因检查自动扩大改稿范围。

## 3. 图表、面板与图注核查

**何时使用：**图文一致性检查、完整整稿审阅和投稿前终检。必须参考 `nature-figure`；涉及统计内容时同时参考 `nature-statistics`，不因检查自动开展新分析。

**检查过程：**

1. 从当前稿件和补充材料枚举全部图表及图中面板，确认实际图表、编号、图注或表题和正文引用的对应关系。完整审阅逐一覆盖，不能用抽查代表全部图表已检查。
2. 实际查看每张图及各面板，同时阅读图注和正文对应论述。核对图中展示的关系是否承担相应论证任务，图注是否足以理解图，而正文是否准确解释其内容。
3. 按图的类型检查适用项：对象与条件、横纵轴及单位、颜色与符号编码、面板标记、缩写、尺度或尺度尺。概念图核对结构、箭头与符号含义；数据图核对比较条件及显示处理。对表格核对表题、行列含义、单位、缩写、视觉强调与脚注，使表格及说明能够独立理解。
4. 涉及统计时核对汇总量、实验或推断单位、样本量 `n` 的含义、独立样本与重复测量、误差线所表示的量，以及适用的检验与比较说明。不能凭图形猜出缺失的统计信息，也不强加不适用的统计项目。
5. 对照图、图注、正文及相关补充中的数字、方向、条件和结论，检查有无冲突、遗漏或过度解释；修改时同步处理必要关联位置。
6. 最终产物可用时，在实际阅读尺寸下检查文字、符号、面板与图注的可读性和对应关系，避免源文件正确但导出后缺失、错位或不可辨认。

**完成标准与边界：**每张图及面板、每个表格都有实际检查依据，问题能定位到图表、面板、说明或正文；明确哪些项目不适用，哪些因缺材料仍未核实。缺少实际图像时只能完成文本检查，不能把整张图标为通过。

本节用于审阅，不自动生成或重绘图像。图像生成与编辑仍遵循入口规定的 `imagegen` 分工；真实数据图保留可核查的数据与标准绘图过程，不能让图像生成工具补造观测值。

## 4. 正文与附录、补充材料双向核查

**何时使用：**正文与补充的组织、编号或内容发生调整，完整整稿审阅，以及投稿前终检。

**检查过程：**

1. 从正文出发逐项检查附录、补充章节、图表、公式或其他材料的引用：目标是否存在，编号是否正确，实际内容是否兑现正文所承诺的定义、推导、设置或分析。
2. 从附录和补充反向检查：各部分是否具有明确作用，是否与主文论证相关，必要时能否从正文找到入口；同时核对两处的术语、符号、条件、统计口径与结论。
3. 引用入口应符合阅读需要，可以在章节层级指向成组推导或细节；不要求每个中间公式、每项辅助材料都获得单独的正文引用。
4. 对孤立材料先判断其必要性与位置。需要保留且有作用的内容建立合适入口；无论证或检查作用的材料考虑删除或重组，不能机械补一句“见附录”就视为问题解决。
5. 核对主文能否独立建立主要结论。理解核心设计或判断关键结论所必需的解释，不应仅留在附录等待读者自行寻找。
6. 最终 PDF、Word 或其他交付物可用时回查真实编号、引用目标和内容；源文件标签存在、链接可点或编译成功均不能代替内容兑现检查。

**完成标准与边界：**双向对应有实际内容依据，失效引用、内容不符与无明确作用的材料已定位；缺失材料保留为待办。完成引用修补不等于完成论证，不能用目录齐全或编译成功宣称通过。

## 5. 全量被引文献核验

**何时使用：**引用核验、完整整稿审阅与投稿前终检。必须实际参考 `nature-academic-search` 和 `nature-ref-verifier`；按入口处理缺失依赖，不以提及名称代替执行。

**覆盖范围：**完整终检以最终正文、图表及图注、脚注和补充材料中实际引用的全部文献为准，支持作者—年份制和编号制。提取被引条目并去重，保留对应引用入口；排除仅存在于 `.bib` 或其他文献库、却未在最终稿使用的条目。局部任务只核验授权范围，不称为全量核验。

**检查过程：**

1. 将实际引文与参考文献表逐项对应，检查缺条、错配、重复与作者—年份歧义。对最终输出重新确认引用集合，不能仅按早期稿件或文献库清单计算覆盖。
2. 对每一被引条目检索并实际读取可得的原始来源记录，优先核对出版方、原论文或正式存储库；按需交叉核对其他可靠书目来源。核验作者姓名及顺序、题名、年份、刊物或会议、卷期、页码或文章编号，以及 DOI、其他标识符和链接等适用字段。区分出版格式允许的作者列表省略与原始书目记录漏人，不把合法的缩写和排版差异当成事实错误。
3. 核对版本身份：预印本、会议版、期刊版及后续修订不能仅凭相似标题视作同一条完整记录。确认稿件实际采用的版本，避免把不同版本的字段拼在一起；有差异时保留来源及差异依据。
4. 为每条文献保留核验状态、来源位置、核对结果与待办，使用下述状态或含义等同的标记。自动匹配或单次检索命中不直接计为已核实。
5. 保留全量清单的覆盖位置和数量：实际被引文献总数，以及各状态的条目数。去重规则保持一致，各状态计数能够对应总数；列出尚未解决的条目及原因，不用总通过率掩盖具体缺口。

**核验状态：**

- **未尝试：**尚未开展该条的来源查找与字段核对。
- **未核实：**已尝试，但来源无法取得、字段信息不足或版本身份尚无法确认。
- **发现差异：**已发现稿件与可靠来源的字段或版本不一致，尚待更正或确认；保留双方依据。
- **已核实：**适用字段及版本已经与实际查阅的来源一致，或差异已解决并复核。

**完成标准与边界：**“已检查全部条目”表示所有实际被引文献均已尝试核验，可以仍有明确列出的未决项；“全部核实”要求所有条目均达到已核实状态，不能含未尝试、未核实或待解决的差异。单个数据库未检出、链接失效或出现 404 均不足以判定文献虚构，应补查其他可靠来源并保留不确定性。

书目信息真实只说明文献及其版本可以确认，不代表它支持稿件中的具体判断。引用能否支持主张，继续执行[关键主张—证据对应](review-workflows.md#2-关键主张证据对应)，实际阅读相关论述及上下文；不能用书目核验通过关闭内容支持方面的问题。
